# 👋 About Me

I'm **Tyron**, an **AI / Machine Learning Engineer** focused on building production-ready AI systems and the engineering infrastructure behind them.

⚙️ I work at the intersection of **machine learning, software engineering, and cloud infrastructure**, taking ideas from experimentation through to reliable, scalable production systems.

🤖 My interests span **Machine Learning, Generative AI, LLMs, MLOps, AI agents, and AI-powered applications**. I'm particularly interested in how we can engineer AI systems that are not only intelligent, but also observable, maintainable, and production-ready.

🏗️ I enjoy designing systems from the ground up, thinking about **architecture, APIs, data pipelines, model lifecycle, deployment, monitoring, CI/CD, and infrastructure** rather than treating ML as an isolated modelling problem.

🚀 I'm also exploring **AI-assisted software engineering and agentic development**, using AI coding tools as engineering leverage while keeping architecture, technical decisions, and code quality firmly under human control.

📚 I'm constantly learning across **AI, distributed systems, software architecture, cloud engineering, and MLOps**, with a focus on becoming a stronger end-to-end engineer.

### What I Build

* 🤖 AI & Machine Learning Systems
* 🧠 LLM & Generative AI Applications
* ⚙️ MLOps & ML Infrastructure
* 🏗️ Software & System Architecture
* 🔄 Data & ML Pipelines
* ☁️ Cloud-Native Applications
* 🚀 AI-Powered Products & Automation

I'm interested in building things that move beyond notebooks and prototypes, **systems that actually work in production.**
